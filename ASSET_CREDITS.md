# Exercise image assets

The exercise start/end photographs in `public/exercises` are adapted from
[Free Exercise DB](https://github.com/yuhonas/free-exercise-db), which publishes
the dataset under the [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md).

The source JPEGs were resized, padded and converted to WebP for Joxo Training.
Exercise names, Swedish coaching copy and the app interface are original to this
project. Hevy was used only as a product-layout reference; no Hevy media or brand
assets are included.
